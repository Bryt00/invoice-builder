1. Encryption in Transit & At Rest

All web traffic to Teks-Invoice is encrypted using TLS 1.3. User passwords are salted and hashed using high-cost bcrypt algorithm. Sensitive access tokens and session data are stored securely.

2. Paystack PCI-DSS Payment Gateway

Payment transactions are handled exclusively by Paystack, a certified PCI-DSS Level 1 payment processor. No raw payment credentials pass through or reside on our servers.

3. Unique Token Public Verification

Public client invoices are secured via cryptographically generated 256-bit public tokens (`public_token`), ensuring public invoice links cannot be guessed or enumerated.

4. Database Isolation & Access Controls

Strict user-id row-level authorization guarantees that your client database and business details are accessible only by your authenticated session.
